# Pass Manager Application

This is a simple Spring Boot web application for managing Meeting pass. It allows Admin to create, read, update, and delete (CRUD) Meeting pass for attendee.

## Technologies Used

•   **Java** 

•   **Spring Boot**

•   **Spring Data JPA**

•   **Hibernate**

•   **MySQL** 

•   **Maven** 

•   **Thymeleaf**
